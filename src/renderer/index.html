Plug in an iPhone or iPad (unlocked, with “Trust This Computer” tapped) to read its full identity, battery health, storage, software and ownership status. Read-only — nothing is changed on the device.

One-time setup: install Apple device support

  1. Apple driver: install Apple’s Mobile Device driver via iTunes or the free Apple Devices app from the Microsoft Store (provides the USB connection service).
  2. Reader tools: get a vetted copy of the open-source libimobiledevice Windows tools (a .zip with ideviceinfo.exe, idevice_id.exe, idevicediagnostics.exe and their DLLs), then click Install from file…. They’re saved next to the app so they travel with it on a USB stick.
  3. Connect a device, unlock it and tap Trust, then press Read device.
